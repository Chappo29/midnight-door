Карамельная ночь / Candy Night

Интерфейс собран как леденец: глянцевые желейные кнопки с толстым тёмным контуром (как у спрайтов), тёмный нижний край для «нажимаемого» объёма, блик сверху. Красно-белая карамельная полоска — акцент (как на пушках). Мятно-клубнично-виноградная палитра на глубоком ночном фиоле. Шрифт «Baloo 2» для заголовков, «Nunito» для текста — оба с полной поддержкой кириллицы.
